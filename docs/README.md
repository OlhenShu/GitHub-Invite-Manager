# Документація GitHub Invite Manager

Вебзастосунок для менторів: **створити репозиторії з шаблону** і **запросити студентів** як колабораторів.

Працює у двох схемах:

- через **організацію** GitHub (`my-org/lab-01`);
- без організації — репозиторії на **особистому акаунті** ментора (`yourname/lab-01`).
